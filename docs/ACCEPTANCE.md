# Acceptance after deployment

Use your own disposable test accounts. Local package checks cannot validate your hosted account settings.

1. Coach signs in, changes the initial password and can create a client.
2. Client signs in, changes password, sees only their assigned content and cannot edit coach master records.
3. A second client cannot view the first client's private records or photos. Check in separate browser sessions.
4. Assign a published training/nutrition/cardio/supplement plan; confirm persistence after reload and that editing a shared template does not alter assigned copies unexpectedly.
5. Check water logging, calorie/macros, meal-photo buttons and private chat with its unread badge.
6. Open Tempo, How Much Weight You Should Lift and How Hard You Should Train in English and Arabic; check six chapters, pictures and RTL layout.
7. Check login videos, exercise/cardio images, both image preferences, desktop and a real smartphone.
8. Coach locks/resets a client account; verify access and password-change requirements.
9. Confirm backup access and that only public/ is served. Inspect function logs for failures and verify custom-domain origin settings if used.
